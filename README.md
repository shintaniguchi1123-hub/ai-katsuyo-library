# このフォルダについて

社内AIポータル「AI活用ライブラリー」を作るための、研修（第4回〜第6回）の成果物をまとめたフォルダです。

## ファイル一覧

| ファイル | 役割 |
|---|---|
| `第6回へ.html` | 第6回時点の要件と、Claude Design／Claude Code に貼る依頼文をまとめた資料。ブラウザで開いて読む |
| `要件.md` | 第6回のグリル（質問セッション）で確定した最新の要件まとめ。仕様の正本はこちら |
| `README.md` | このファイル |
| `CLAUDE.md` | このフォルダで作業するときのルール（Claude Code向け） |
| `社内AIポータル.html` | 実際に動くアプリ本体 |
| `index.html` | 公開ページの入口。開くと `社内AIポータル.html` に移動する |

## 経緯

1. 第4回：社内AIポータルの要件を決めた
2. 第5回：Claude Design でワイヤーフレームを作った（`第6回へ.html` の②の依頼文）
3. 第6回：要件と依頼文を1枚に整理し、作る前に決めておくべきことをグリル（質問セッション）で詰めた。結果を `要件.md` に反映済み

## 次にやること

`第6回へ.html` の③「Claude Code に貼る依頼文」と `要件.md` を Claude Code に渡し、`index.html` としてアプリ本体を作ってもらう。

```
1. 第6回へ.html を開く
2. ③の依頼文の枠内をコピー
3. Claude Code に貼って、要件.md も参照するように伝える
```

## 前提

これは研修用のプロトタイプです。データはブラウザ内（localStorage）にのみ保存され、他の端末とは共有されません。本番運用にはサーバー側の作り直しが必要です（詳細は `要件.md` を参照）。
