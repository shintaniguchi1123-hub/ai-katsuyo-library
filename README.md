# このフォルダについて

社内AIポータル「AI活用ライブラリー」を作るための、研修（第4回〜第6回）の成果物をまとめたフォルダです。

## ファイル一覧

| ファイル | 役割 |
|---|---|
| `第6回へ.html` | 第6回時点の要件と、Claude Design／Claude Code に貼る依頼文をまとめた資料。ブラウザで開いて読む |
| `要件.md` | 第6回のグリル（質問セッション）で確定した最新の要件まとめ。仕様の正本はこちら |
| `README.md` | このファイル |
| `CLAUDE.md` | このフォルダで作業するときのルール（Claude Code向け） |
| `社内AIポータル.html` | アプリの画面 |
| `functions/api/[[path]].js` | アプリのサーバー側（ログインとデータの保存。Cloudflare 上で動く） |
| `index.html` | 公開ページの入口。開くと `社内AIポータル.html` に移動する |

## 経緯

1. 第4回：社内AIポータルの要件を決めた
2. 第5回：Claude Design でワイヤーフレームを作った（`第6回へ.html` の②の依頼文）
3. 第6回：要件と依頼文を1枚に整理し、作る前に決めておくべきことをグリル（質問セッション）で詰めた。結果を `要件.md` に反映済み
4. 実際に使う形へ：データを共有データベース（Cloudflare D1）に保存し、ログインをサーバー側で行うように作り直した

## 公開先

- 公開ページ：https://ai-katsuyo-library.pages.dev
- GitHub の main ブランチに送ると、自動で公開し直されます。Cloudflare 側の設定は `要件.md` の「8. Cloudflare 側の設定」を参照。

## はじめて使うとき

1. 公開ページを開くと「はじめの設定」画面が出る
2. Cloudflare に登録した初期設定キーを入れて、経営サイドのアカウントを作る
3. マイページ →「アカウント・店舗の管理」で、店長・社員のアカウントを発行する
