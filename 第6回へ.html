要件のまとめ

この仕組みは何のためにあるか

社内で見つけた「うまくいったAIの使い方」を、お手本としてためていく場所です。一人の工夫を全員が見て・まねできるようにして、AI活用をお店全体に広げます。

使う人は誰か

店長と社員が見ます。投稿するのは経営サイドと店長だけ。社員は見る・反応する・質問する・保存する側です。一人ひとり別のID・パスワードでログインするので、誰の投稿・質問かが分かります。

この仕組みに必要なもの（上から大事な順）

  1. 1件ずつの投稿。ひと目で分かるタイトル＋「①やりたかったこと／②できなかったこと／③なぜできなかったか／④出てきた結果／⑤その対策」
  2. 使ったプロンプト（Claudeに送った言葉）と、ワンタップのコピーボタン
  3. 3店舗運営を前提に、投稿は店舗をまたいで全員に共有する。投稿カードに店舗名を表示し、店舗での絞り込み表示もできる
  4. カテゴリで分類（クチコミ返信・会議のアジェンダ作り・シフト作成・発注・新人教育・メール/お知らせ作成／あとから追加できる。追加できるのは経営サイドだけ）
  5. トップの見せ方：おすすめ（ピン留め）→ 新着 → カテゴリ一覧。役立った順（いいね＋試した＋真似したいの合計）・よく見られた順（閲覧数）で並べ替え
  6. リアクション3つ（いいね・試した・真似したい／もう一度押すと取り消せる）
  7. 質問できる → 投稿した本人が答える
  8. お気に入り保存
  9. 写真・スクショも載せられる（1投稿につき最大3枚）
  10. 新しい投稿が出たら、開いたとき画面上にお知らせ
  11. 経営サイド向けの集計（今月の投稿数・よく見られたお手本など。全店舗合算に加えて店舗別の内訳も見られる）
  12. 直す・消すは、投稿した本人と経営サイドだけ

置かないと決めたもの

  • 社員からの投稿（社員は見る側にする）
  • 失敗だけを集めたページ（成功も失敗も1件の中にまとめる）
  • 名前を出さない匿名の投稿（誰が投稿したか分かるようにする）

まだ決まっていないこと

  • データの保管場所（仮：いまは端末の中だけに保存。他の端末には投稿が反映されないため、画面上にも試作版である旨の注意書きを表示する。本番は全員で共有するサーバーに載せかえる）
  • 投稿を出す前のチェックの有無（仮：チェックなしで、投稿したらすぐ全員に見える）
  • 古い投稿の扱い（仮：消さずに残し、並べ替えで自然に下がるだけにする）

Claude Design に貼る依頼文

下の枠の中を、そのままコピーして Claude Design に貼ってください。

コピーして貼る

社内で使う「AI活用ライブラリー」というWebアプリの画面をデザインしてください。まずは色を使わず、白・黒・グレーだけの骨組み（ワイヤーフレーム）として作ってください。装飾や色づかいはこの段階では不要で、どこに何を置くか、画面の構成だけが分かる形にしてください。

このアプリは、社内で見つけた「うまくいったAIの使い方」をお手本としてためていく場所です。一人の工夫を全員が見てまねできるようにして、AI活用をお店全体に広げるのが目的です。飲食店を3店舗運営していて、見る人は各店舗の店長と社員です。投稿するのは経営サイドと店長だけで、社員は見る・反応する・質問する・保存する側です。投稿は店舗をまたいで全員に見えるようにし、どの店舗の投稿かが分かるようにします。主にスマホで見ます。

これはまだ試作段階で、投稿データは今使っている端末の中だけに保存され、他の端末には反映されません。そのため画面のどこかに、試作版である旨の小さな注意書きを置いてください。

画面の文字はすべて日本語にしてください。

作ってほしい画面は次のとおりです。

トップ画面：上に検索バーと、カテゴリ・店舗の絞り込み、その下に「おすすめ（ピン留めした投稿）」、続いて「新着の投稿一覧」を並べる。投稿は新着順・役立った順・よく見られた順で並べ替えられるようにする。一覧の各投稿カードには、タイトル、カテゴリ、店舗名、投稿した人の名前、いいねの数、閲覧数を表示する。新しい投稿があるときは画面上部にお知らせのバナーを出す。画面の下にはメニュー（ホーム・カテゴリ・投稿ボタン・保存・マイページ）を置く。

投稿の詳細画面：ひと目で分かるタイトルと、「①やりたかったこと ②できなかったこと ③なぜできなかったか ④出てきた結果 ⑤その対策」の5項目、使ったプロンプト（AIに送った言葉）とそれをコピーするボタン、写真の欄（最大3枚）、リアクション3種（いいね・試した・真似したい。押し直すと取り消せる）、保存ボタン、そして質問を書き込む欄と投稿者からの回答を表示する欄を置く。

投稿フォーム画面：タイトル、カテゴリの選択（新しいカテゴリを追加する導線つき）、上記の5項目の入力欄、プロンプトの入力欄、写真の追加欄を並べる。

カテゴリ一覧画面：仕事の種類（クチコミ返信・会議のアジェンダ作り・シフト作成・発注・新人教育・メール/お知らせ作成）をタイル状に並べ、それぞれ何件のお手本があるか表示する。

集計画面：経営サイド向けに、今月の投稿数、累計の投稿数、よく見られたお手本のランキング、カテゴリ別の投稿数を全店舗合算で表示し、あわせて店舗ごとの投稿数の内訳も表示する。

ログイン画面：一人ひとり別のIDとパスワードでログインする形にする。

Claude Code に貼る依頼文

下の枠の中を、そのままコピーして Claude Code に貼ってください。

コピーして貼る

社内で使うWebアプリ「AI活用ライブラリー」を作ってください。社内で見つけた「うまくいったAIの使い方」をお手本としてためていき、あとから誰でも見て・まねできる社内ポータルです。ぜんぶを1枚のHTMLファイルにまとめて、ブラウザで開けばそのまま動くようにしてください。追加でインストールが必要な仕組みは使わないでください。

会社は飲食店を3店舗運営しています。使う人は各店舗の店長と社員です。投稿できるのは経営サイドと店長だけで、社員は見る・反応する・質問する・保存する側です。投稿は店舗の垣根なく全員に見えるようにし、どの店舗の投稿かが分かるように店舗名を表示してください。一人ひとり別のIDとパスワードでログインし、誰の投稿・質問かが分かるようにしてください。主にスマホで見るので、スマホで見やすい画面にしてください。文字はすべて日本語にしてください。

これはまだ試作段階のプロトタイプです。ログイン情報や投稿データは、今使っている端末のブラウザの中だけに保存する形でよく、パスワードも平文のまま保存して構いません（本番稼働の際はサーバー側の認証・データ保存に必ず作り直してください）。この試作は端末ごとにデータが独立しており、他の人の端末には投稿が反映されないため、画面のどこか（例：ログイン画面やトップ画面の上部）に「試作版：投稿はこの端末の中だけに保存されます」といった注意書きを小さく表示してください。

ログイン用のアカウントは、新規登録画面を作らず、コードの中にあらかじめ用意しておいてください。経営サイド1件（全店舗の投稿・集計を見られる）、各店舗に店長1件、各店舗に社員2件程度、あわせて3店舗分を用意してください。

画面に置くものは、上から順に次のとおりです。

ログイン画面（ハードコードされたIDとパスワードで、一人ひとり別に入る）。

トップ画面。上に検索バーと、カテゴリ・店舗の絞り込みを置く。その下に「おすすめ（ピン留めした投稿）」、続いて投稿の一覧。投稿は新着順・役立った順（いいね＋試した＋真似したいの合計が多い順）・よく見られた順（閲覧数が多い順）で並べ替えられるようにする。各投稿カードにはタイトル、カテゴリ、店舗名、投稿した人の名前、いいねの数、閲覧数を表示する。新しい投稿（自分が最後に見たときより後に投稿されたもの）があれば、画面上部にお知らせのバナーを出す。画面の下にメニュー（ホーム・カテゴリ・投稿ボタン・保存・マイページ）を置く。

投稿の詳細画面。タイトルと、「①やりたかったこと ②できなかったこと ③なぜできなかったか ④出てきた結果 ⑤その対策」の5項目、使ったプロンプト（AIに送った言葉）とそれをコピーするボタン、写真（1投稿につき最大3枚、アップロード時に自動で縮小してから保存）、リアクション3種（いいね・試した・真似したい。それぞれもう一度押すと取り消せるトグル式にする）、保存ボタン、質問を書き込む欄と投稿した本人が回答する欄を置く。閲覧数は、この画面を開くたびに1増やす。

投稿フォーム画面。タイトル、カテゴリの選択、上の5項目の入力欄、プロンプトの入力欄、写真の追加欄（最大3枚）を並べる。カテゴリの選択欄には「＋新しいカテゴリを追加」の導線を置き、これは経営サイドだけが使えるようにする。経営サイドは、その投稿を「おすすめ」に固定できるようにする。

カテゴリ一覧画面。仕事の種類（クチコミ返信・会議のアジェンダ作り・シフト作成・発注・新人教育・メール/お知らせ作成）をタイル状に並べ、それぞれ何件あるか表示する。

集計画面（経営サイドだけが見られる）。今月の投稿数、累計の投稿数、よく見られたお手本のランキング、カテゴリ別の投稿数を、全店舗の合算で表示する。加えて、店舗ごとの投稿数の内訳も表示する。

そのほかの決まりごと。投稿を直す・消せるのは、投稿した本人と経営サイドだけにする。写真・スクショも投稿に載せられるようにする。あらかじめ、3店舗・複数カテゴリにまたがるサンプル投稿を5件ほど（うち1件はおすすめピン留め）入れた状態で起動するようにしてください。
